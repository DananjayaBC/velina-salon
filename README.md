# Salon Apsa — Luxury Beauty Salon Website (Template 2)

Landing page for **Salon Apsa**, a luxury beauty salon offering bridal beauty, hair artistry, skin rituals and nail care.

**Style:** minimal editorial layout on warm off-white, light uppercase headlines with calligraphic script accent letters, tiny uppercase labels, hairline dividers, moody dark photo bands. Inter + Pinyon Script fonts.

**Sections:** Hero · About · Curated Beauty Services · Real Transformations · Elevated Beauty Experience · Gallery · Client Experiences · Reserve CTA · Footer.

Built with Next.js 16 (App Router), TypeScript and Tailwind CSS v4. Fully responsive (mobile, tablet, desktop).

```bash
npm install
npm run dev   # http://localhost:3000
```
